# Submission source

LaTeX source for *Composition Without Contribution: A Controlled Ablation of
Multi-Paradigm Neural Classifiers for Non-Functional Requirements*, prepared for
Empirical Software Engineering.

## Build

```bash
pdflatex main
pdflatex main
```

Two passes are needed so that cross-references resolve. There is no `.bib` file and no
BibTeX run: the bibliography is a `thebibliography` environment inside `main.tex`, which
keeps the source self-contained. Output is 28 pages.

## Contents

```
main.tex          manuscript source, 1,760 lines
figures/          six figures, PDF, drawn at exact display width
README.md         this file
```

Figures are vector PDF generated by `code/make_figures.py` in the replication package.
Each is drawn at the width it is displayed at, so nothing is rescaled by LaTeX and no
text is resampled. Regenerating them from the released prediction files reproduces them
exactly.

## Switching to Springer's official class

The manuscript currently builds with stock LaTeX in a layout close to Springer's.
Springer does not permit redistribution of `sn-jnl.cls`, so it is not bundled here.
Obtain it from the Springer Nature LaTeX author support pages or from the Overleaf
template gallery, then:

1. Place `sn-jnl.cls` beside `main.tex`.
2. Replace the `\documentclass` line with
   `\documentclass[sn-mathphys-num,iicol]{sn-jnl}`.
3. Delete the preamble block marked `STOCK-LAYOUT ONLY`, which supplies the geometry,
   author and section formatting that `sn-jnl` provides itself.
4. Convert the title block to `sn-jnl` syntax (`\title`, `\author`, `\affil`) and wrap
   the abstract in `\abstract{}`.

Floats, equations, tables and the bibliography compile unchanged under either class. The
header comment in `main.tex` repeats these instructions.

## Line numbers

Reviewers frequently ask for them. Two commented lines near the top of the preamble
enable `lineno`; uncomment both.

## Verification

Every quantitative claim in the manuscript is checked against the released data by
`code/verify_paper.py` in the replication package, which exits non-zero if any reported
value disagrees. At the time of writing it reports 78 of 78 claims verified.

## Before submitting

- Register the replication package with a repository that issues a DOI and insert it in
  the Declarations section, which currently carries a placeholder.
- Confirm the references listed in `CITATION_CHECKLIST.md` against their sources.
- Confirm the licence terms of both source datasets, recorded in `sources/SOURCES.md`
  in the replication package.
